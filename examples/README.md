# Examples and Test Suite

This directory contains the test suite for the compiler. The tests are structured to be deterministic, categorized, and easily machine-processable.

## Directory Structure

```
examples/
  README.md         # This file
  manifest.json     # Single source of truth for all tests
  valid/            # VALID C programs (expected to compile and run)
    <category>/
      <id>_<slug>/
        program.c        # Source code
        expected.txt     # Expected numeric return value (exit code)
        program.ir       # Golden IR file (generated by compiler)
  invalid/          # INVALID C programs (expected to fail compilation)
    <category>/
      <id>_<slug>/
        program.c        # Source code
        expected_error.txt # Expected error pattern/category
```

## Categories

**Valid:**
- `basics`: Minimal programs, return constants, variables.
- `arithmetic_int`: Integer arithmetic (+, -, *, /, %, unary).
- `arithmetic_float`: Floating point arithmetic.
- `comparisons`: Relational operators.
- `control_flow`: If/else, loops, break/continue.
- `functions`: Function calls, recursion.
- `arrays`: Array declaration and access.
- `pointers`: Pointer arithmetic and dereferencing.
- `structs`: Structures.
- `casts`: Type casting.
- `const`: Const qualifier.
- `stress`: Complex programs.

**Invalid:**
- `syntax`: Parse errors.
- `sema_types`: Type mismatches, invalid operations.
- `sema_control`: Invalid control flow (e.g., break outside loop).
- `sema_defs`: Redefinitions, incomplete types.
- `sema_uninit`: Usage of uninitialized variables.
- `sema_other`: Other semantic errors.

## Running Tests

Use the compiler CLI to run the test suite:

```bash
java -jar ccompiler.jar test
```

Or using the maven wrapper if available:

```bash
./run.sh test
```

## Manifest Format

The `manifest.json` file contains a list of test definitions:

```json
[
  {
    "id": "0042",
    "path": "valid/structs/0042_struct_nested",
    "valid": true,
    "category": "structs",
    "tags": ["struct", "nested"],
    "expected": {
      "return": "15"
    }
  },
  {
    "id": "9001",
    "path": "invalid/sema_types/9001_bad_cast",
    "valid": false,
    "category": "sema_types",
    "expected": {
      "error": {
        "pattern": "type mismatch"
      }
    }
  }
]
```

## Adding a New Test

1.  Choose the appropriate category in `valid/` or `invalid/`.
2.  Create a new folder `NNNN_slug_name` (increment ID).
3.  Add `program.c`.
4.  For valid tests:
    -   Compile with `gcc` to verify behavior and get return value.
    -   Add `expected.txt` with the return value.
    -   Run the compiler IR generator to create `program.ir`.
5.  Add entry to `manifest.json`.
